# Contributing to MSL

Thanks for your interest in contributing to MSL.

MSL is a small project, and contributions of all sizes are welcome. You do not need to be an expert or already know the entire codebase.

## Before you start

For larger changes, open an issue or discussion first. This helps avoid spending time on something that does not fit the project.

For small fixes, documentation changes, or obvious bugs, feel free to open a pull request directly.

## What you can contribute

Anything useful is welcome, including:

* Bug fixes
* Features and improvements
* Documentation
* Testing
* Linux application compatibility
* UI and design work
* Build and development tooling
* Bug reports and reproduction cases

You do not have to write code to contribute.

## Pull requests

Please keep pull requests focused on one change where possible.

Include a short explanation of:

* What you changed
* Why you changed it
* How you tested it

If your change affects MSL's behaviour or user experience, please mention that too.

## Code

MSL is primarily written in Swift, with some C and shell code.

There is no need to follow a giant style guide. Keep changes consistent with the surrounding code, avoid unnecessary complexity, and prefer simple solutions.

Please do not introduce a new dependency unless it is actually needed.

## Testing

Test your changes before submitting a pull request.

If your change affects Linux application support, test with the relevant application if possible. If something does not work, say so. A known limitation is much more useful than pretending everything is fine.

## Issues

When reporting a bug, include whatever information you have that might help reproduce it.

Useful things include:

* macOS version
* Mac model
* MSL version
* Linux distribution
* The application involved
* What you expected to happen
* What actually happened
* Steps to reproduce

Screenshots, logs, and minimal reproduction cases are always helpful.

## Recognition

Contributors get a little something extra in MSL.

Once you've made a meaningful contribution, your GitHub profile picture can appear in the **bottom-left corner of the MSL graphical app** and in its **Contributors** tab.

## Questions

If you are unsure about something, ask.

There is no expectation that contributors understand every part of MSL before contributing. Some parts of the project are considerably more cursed than others.

Thanks for helping make MSL better.
