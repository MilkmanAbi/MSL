Experimental Features

What experimental means here

Why these are switches rather than simply how MSL works, and what to do when one misbehaves.

Experimental Features is in the sidebar, under the instance list. It is the only place any of these change, and it says how many are on.

They are on, and they still might bite#

Most of these start on, because MSL is much less pleasant without them: a Mac keyboard that does nothing in Linux apps, a clipboard that stops at the window edge, menus drawn inside the window instead of in the menu bar.

They are still called experimental, and that word is doing real work:

important

What "experimental" is warning you about

Each of these reaches into software MSL did not write — a toolkit's idea of where its file dialog comes from, an app's idea of what Ctrl+C means, a desktop's idea of who owns the menus. MSL can be completely correct and an app can still do something odd, because the app has its own opinion.

So they can have occasional stability issues: an app whose menus do not appear, a dialog that opens in the wrong place, a shortcut that lands somewhere unexpected. None of it damages anything, and every one of them is a switch.

If something behaves strangely, turn the matching switch off. Everything goes back to how that app behaves on an ordinary Linux desktop. That is the whole point of them being switches, and it is a better first move than working around the symptom.

When a change takes effect#

Each switch carries a small badge saying when it applies:

BadgeMeans
LiveStraight away, including for apps already open.
New appsApps launched after the change. Ones already running keep the old behaviour.
RestartThe instance has to be restarted.

A switch that says New apps has not failed if nothing changes in the window you are looking at — close the app and open it again.

Grouped by what they change#

GroupWhat it covers
Graphics and input (mslgd)How Linux windows look and how they take the keyboard and mouse.
Peripherals (mslps)The Mac's camera and microphone, for Linux apps.
MSLWhere Linux and the Mac meet: links, files, the clipboard, the menu bar.

Reset all at the top puts every switch back to what MSL ships.

note

Settings you have chosen are kept

When a later version of MSL turns something on by default, it changes only that switch. Anything you have set for yourself stays as you left it.
