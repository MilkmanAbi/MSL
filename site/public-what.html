Reaching it from anywhere

What publishing does

Gives an instance an address that works from any computer, anywhere.

MSL's normal SSH gets you into an instance from this Mac. Publishing gets somebody in from anywhere — a laptop on another network, a phone, a colleague's machine.

That turns an instance into a small server: something you leave running and reach when you need it.

You get back an address and the command to use it:

Anyone with that address, and a key you've allowed, can log in with ordinary ssh. They need no account, no MSL, and nothing installed — which is the whole point of doing it this way.

How it works#

The tunnel runs on your Mac, not inside the instance. MSL already reaches the guest's SSH port on your local network, so it forwards that through a relay and out to the internet. The instance itself is never changed to make this work, and nothing is installed in it.

What it costs#

By default MSL uses a free public relay, which means two honest limits:

Free relayYour own server
AddressRandom, and changesYours, and stays
SessionAbout an hour, then renewed at a new addressNo limit
NeedsNothingA machine you can already ssh to

The free relay is right for "let me show you this". For something you actually depend on, publish through a server you own — see Through your own server.

note

The Mac has to stay awake

While anything is published, MSL stops your Mac going to sleep on its own, and keeps the instance from hibernating. Closing the lid still sleeps it — a laptop in a bag is not a server. MSL reconnects when it wakes, at a new address if it is using the free relay.

Just reaching it from this Mac#

If you only want a server inside Linux to open in a browser on this Mac, you do not need any of this — see Reaching a port inside Linux.
